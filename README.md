# Prisma Nova ✨

Un juego de bloques que caen con gemas, combos y un joyero que no querés que se desborde. Se juega directo en el navegador, en la compu o en el celular, sin instalar nada.

[![Jugar](https://img.shields.io/badge/▶_Jugar-Prisma_Nova-ff6fa5?style=for-the-badge)](https://max1lol.github.io/prisma-nova/)

**https://max1lol.github.io/prisma-nova/**

## Cómo se juega

Encastrá las piezas para completar líneas y tallarlas. Cada línea suma puntos, subís de nivel y la caída se acelera. Encadená líneas seguidas para armar combos.

### Modos

- **Clásico:** el juego base, sin sorpresas.
- **Innovador:** algunas piezas traen gemas, aparecen piezas bomba y de vez en cuando se activa un momento dorado.

## Controles

| Acción | Teclado | Celular |
| --- | --- | --- |
| Mover | ← → | Botones ← → |
| Girar | ↑ | Botón ↻ |
| Bajar | ↓ | Botón ↓ |
| Caída rápida | Espacio | Botón de caída |
| Reservar pieza | C | Botón C |
| Pausa | P | Botón de pausa |

## Características

- Pieza de reserva y vista de la pieza siguiente.
- Puntos, líneas, nivel y combo en tiempo real.
- Tema claro y oscuro.
- Música y efectos de sonido, con volumen ajustable para cada uno.
- Controles táctiles para jugar desde el celular.
- Mejores puntajes guardados en tu navegador, por modo.

## Jugar en tu compu sin conexión

El juego es un solo archivo. Descargá `index.html` y abrilo con tu navegador. Las fuentes se cargan desde Google Fonts, así que sin internet se verán con una tipografía de reemplazo.

## Notas

- Los puntajes se guardan solo en tu dispositivo y no se envían a ningún lado.
- Si borrás los datos del navegador, se borran también los récords.
